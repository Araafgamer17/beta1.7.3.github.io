Standalone Installation Guide

IMPORTANT: Delete META-INF inside minecraft.jar or the game will crash!
Method 1: Manual Injection 1. Open %appdata%\.minecraft\bin\minecraft.jar in 7-Zip or WinRAR.
2. Delete META-INF folder.
3. Copy all `.class` files from mod ZIP into `minecraft.jar`.
Method 2: Prism / MultiMC 1. Edit Instance → Version Tab.
2. Click "Add to minecraft.jar" → Choose downloaded ZIP package.
