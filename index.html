Installation Guide

Standalone Beta 1.7.3 Injection (No ModLoader Required)

Critical Requirement You MUST delete the META-INF folder inside minecraft.jar, or the game will black screen upon startup!

A Vanilla / Default Launcher Method

  1. Press Win + R, type %appdata%\.minecraft\bin and hit Enter.
  2. Open minecraft.jar using WinRAR or 7-Zip.
  3. Delete the folder named META-INF inside the JAR.
  4. Extract all .class files from the downloaded Arcane Expansion ZIP directly into minecraft.jar.
  5. Confirm overwrite when prompted, close WinRAR/7-Zip, and launch Minecraft Beta 1.7.3!

B Prism / MultiMC Launcher Method

  1. Right-click your Minecraft Beta 1.7.3 instance in Prism/MultiMC and click Edit Instance.
  2. Select the Version tab on the left sidebar.
  3. Click Add to minecraft.jar on the right action bar.
  4. Select the downloaded ArcaneExpansion-b1.7.3-v0.9.4-BETA.zip file.
  5. Launch the instance! Prism automatically strips META-INF for you.
