Quick Setup

Notice: Delete META-INF from minecraft.jar or the game will crash.

Manual Installation 1. Open minecraft.jar in 7-Zip/WinRAR.
2. Remove META-INF folder.
3. Copy all class files from mod ZIP into the jar.
Prism / MultiMC 1. Edit Instance → Version tab.
2. Click "Add to minecraft.jar".
3. Select the downloaded ZIP file.
