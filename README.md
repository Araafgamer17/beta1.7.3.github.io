**Arcane Expansion** is a standalone, lightweight magic mod developed for Minecraft Beta 1.7.3[cite: 9]. It seamlessly blends ancient spellcasting, custom block rendering, and new crafting mechanics directly into vanilla gameplay without requiring third-party mod loaders[cite: 12].

---

## ✨ Key Features

* **3D Animated Magic Blocks:** Interactive **Magic Table** and **Pedestals** featuring custom spinning/floating renderers[cite: 12].
* **Magic Crafting Table:** Specialized crafting station for magical components and recipes[cite: 12].
* **Wands & Spellcasting:** Custom **Magic Wand** with integrated left-click attack detection[cite: 12].
* **Enchantment Overhauls:**
  * **Mending:** Repair held items using XP via Shift + Right Click[cite: 12].
  * **Silk Touch & Fire Aspect:** Fully functional block dropping and target ignition mechanics[cite: 12].
  * **Enchanted Books:** Custom GUI viewer (`GuiEnchantedBook`) and dedicated inventory icons[cite: 12].
* **New Items:** Book & Quill, Bottle o' Enchanting, Magic Crystal, and custom magic gear[cite: 12].
* **In-Game HUD & Interface Overrides:** Custom non-flickering HUD status overlay and styled main menu branding[cite: 12, 13, 14].

## 🛠️ Installation Guide

### Method 1: Prism Launcher / MultiMC (Recommended)
1. Open your **Minecraft Beta 1.7.3** instance settings.
2. Navigate to the **Version** tab on the left sidebar.
3. Click **Add to minecraft.jar** on the right sidebar.
4. Select the downloaded `Arcane.ExpansionBeta1.7.3_01.zip` file.
5. Launch the game!

### Method 2: Manual Injection
1. Navigate to `%appdata%\.minecraft\bin\`.
2. Open `minecraft.jar` using 7-Zip or WinRAR.
3. **CRITICAL:** Delete the `META-INF` directory inside `minecraft.jar`.
4. Copy all `.class` files and assets from `Arcane.ExpansionBeta1.7.3_01.zip` directly into `minecraft.jar`.
5. Close the archive and launch Minecraft.
