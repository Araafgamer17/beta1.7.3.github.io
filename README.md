## 📖 Installation Instructions

> ⚠️ **IMPORTANT**: You MUST delete the `META-INF` folder inside your `minecraft.jar` file if installing manually, or the game will crash on startup!

### Method 1: Manual Jar Patching (Vanilla / Launcher)

1. Open `%appdata%\.minecraft\bin\minecraft.jar` using 7-Zip or WinRAR.
2. Delete the **`META-INF`** folder.
3. Open the downloaded mod **ZIP** file and drag/copy all `.class` files directly into `minecraft.jar`.
4. Launch your game!

### Method 2: Custom Launchers (Prism Launcher / MultiMC)

1. Open your instance settings and navigate to the **Version** tab.
2. Click **Add to minecraft.jar** (or *Add Jar Mod*).
3. Select the downloaded `Arcane.ExpansionBeta1.7.3_01-pre-2.zip` package.
4. Launch the instance!
